# PDaB

PDaB — учебный хоррор от первого лица: процедурный советский подъезд с запутанными коридорами, редким светом и преследователем. Нужно найти выход; безопасное место — под работающей потолочной лампой. Фонарик помогает видеть, но не защищает от врага.

## Запуск готовой игры

В [релизах](https://github.com/afterburnerr/PDaB/releases) находится архив для Linux x86_64. Распакуйте его целиком и запустите `PDaB-Linux/run.sh`. Подробности и параметры запуска находятся в `README_RU.txt` внутри архива.

| Кнопка | Действие |
| --- | --- |
| WASD | Движение |
| Мышь | Осмотр |
| Shift | Бег |
| F | Фонарик |
| Esc | Пауза / продолжение |

Для проверки прототипа во время игры можно набрать `easy` (убрать преследователя до перезапуска сцены) или `tp` (переместиться перед выходом; для победы нужно пройти наружу).

Бег и фонарик используют общий запас AUX POWER. Интерфейс рассчитан на **1920×1080** и **1920×1200**.

## Открытие исходников

Откройте папку проекта через Unity Hub в **Unity 6000.6.6f1**. Установите модуль Linux Build Support для сборки Linux. Главная сцена: `Assets/Scenes/SampleScene.unity`. Зависимости зафиксированы в `Packages/manifest.json` и `Packages/packages-lock.json`.

- `Assets/Scripts/Gameplay` — генерация, движение, энергия, враг и управление состояниями игры.
- `Assets/Scripts/UI` — меню, HUD и эффекты приближения врага.
- `Assets/Art`, `Assets/Audio`, `Assets/Characters` — используемые игровые материалы.
- `Tools/Art` — генераторы, сведения об источниках, исходники моделей Blender и превью.
- `Tools/EditorSetup` — скрипты настройки и сборки через подключённый Unity CLI.
- `Tools/Release` — упаковка, проверка целостности и инструкция выпуска.
- `Docs/Practice` — материалы отчёта по практике, если включены в этот выпуск.

Редактируемые модели: `Tools/Art/EntranceLamp/EntranceLamp.blend` и `Tools/Art/Stalker/Stalker.blend`. FBX и текстуры для игры находятся в `Assets`. Не перемещайте файлы из `Assets` без соответствующих `.meta`.

## Сборка и упаковка

Сценарий `Tools/EditorSetup/BuildPDaBLinux.cs` собирает обычный Linux x86_64 player с Mono, без Development Build. Запускается в уже открытом редакторе; не нужно открывать второй редактор на том же проекте. Команды и проверка архивов описаны в [Tools/Release/README.md](Tools/Release/README.md).

## Материалы и авторство

Это неофициальный учебный прототип, вдохновлённый Half-Life и эстетикой старых подъездов. Часть звуков, шрифтов и текстур взята из **Half-Life 2 / Valve**. Сведения об извлечении и источниках сохранены в манифестах `Tools/Art/HalfLife2-*.json`, `Tools/Art/HalfLifeMenuFont.json` и `Tools/Art/StalkerAudioSources.json`. Эти материалы принадлежат правообладателям; репозиторий не объявляет их собственной работой и не предоставляет на них новую лицензию.

Промпты созданных изображений и генераторы моделей сохранены рядом с исходниками в `Tools/Art`. PDaB не связан с Valve и не является официальной игрой серии Half-Life.
