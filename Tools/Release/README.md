# Выпуск PDaB

Нужны Unity 6000.6.6f1 с Linux Build Support, уже открытый проект и Python 3. Публикацию и отправку сообщений эти скрипты не выполняют.

## Проверка исходников

Из корня проекта:

```bash
python3 Tools/Release/package_release.py --audit
```

Проверка перечисляет объём, самые большие файлы, исходники Blender и файлы более 100 МиБ, которым потребуется Git LFS при публикации. Она также проверяет наличие главной сцены, манифестов пакетов, `.blend` лампы и врага, ищет известные форматы случайно сохранённых ключей. Содержимое найденных ключей не печатается.

## Сборка через подключённый редактор

Сначала завершите Play, сохраните сцены и выберите Linux x86_64 как активную платформу. Затем:

```bash
unity --no-banner --non-interactive --json command run_script \
  --file Tools/EditorSetup/BuildPDaBLinux.cs --entry BuildPDaBLinux.Run \
  --project-path "$PWD"
```

Для удаления тяжёлого редакторского превью можно явно вызвать entry `BuildPDaBLinux.ClearPreview` (очистка и сохранение без сборки) или `BuildPDaBLinux.RunClean` (очистка, сохранение, затем сборка). Это удаляет только сгенерированную геометрию и освобождает её mesh-буферы; настройки генератора и ссылки на материалы/префабы сохраняются. При старте новой игры уровень снова создаётся во время загрузки.

Сценарий `Run` отклоняет сборку при несохранённых сценах. Настраивает имя PDaB, Mono, полный экран 1920×1080 и обычную сборку без отладчика. Содержит только `Assets/Scenes/SampleScene.unity`. Результат записывает рядом с проектом, в `../FPLab-Releases/<UTC-время>/PDaB-Linux`; отчёт — в соседний `BuildReport.json`. Существующий выпуск не перезаписывается. Второй экземпляр Unity на том же проекте не запускается.

## Упаковка

Подставьте каталог, возвращённый сборщиком:

```bash
python3 Tools/Release/package_release.py \
  --build-dir ../FPLab-Releases/ГГГГММДД-ЧЧММСС/PDaB-Linux \
  --output ../FPLab-Releases/ГГГГММДД-ЧЧММСС
```

Создаются `PDaB-Linux-x86_64.tar.gz`, `PDaB-Unity-Source.zip`, `SHA256SUMS.txt` и `ArchiveReport.json`. Linux-архив сохраняет исполняемые права `run.sh` и player. Оба архива содержат `RELEASE-MANIFEST.json` с SHA-256 каждого файла; после записи каждый файл читается из архива и проверяется по хешу. ZIP также проверяется по CRC. Временные метки архивов фиксированы, поэтому одинаковые входные файлы дают одинаковые архивы.

Исходный ZIP содержит папку `PDaB` с `Assets` и `.meta`, `Packages`, `ProjectSettings`, `Tools`, готовыми `Docs`, README и настройками Git. Сохраняются редактируемые `.blend`, FBX, текстуры, исходники скриптов, промпты и манифесты происхождения материалов. Исключены Unity-кеши, локальные настройки редакторов/агентов, скрытые папки, среды Python, журналы, Blender recovery-копии `*.blend1` и неиспользованные загрузки `Tools/Art/PodRideResearch`. Символические ссылки отклоняются, чтобы не захватить файлы за пределами проекта.

Проверка опубликованного скачанного архива:

```bash
sha256sum -c SHA256SUMS.txt
```

## Публикация

Исходный репозиторий: `afterburnerr/PDaB`. Для выпуска загрузите в GitHub Release оба архива и `SHA256SUMS.txt`; описание выпуска должно содержать платформу, управление и проверенные ограничения. Перед публикацией проверьте `ArchiveReport.json` и итоговую игровую сборку. В `.gitignore` сохранены те же основные исключения; исходники Blender и Unity `.meta` не исключаются.
