PDaB — Linux x86_64

Распакуйте архив целиком и запустите ./run.sh из папки PDaB-Linux.
Если файловый менеджер не разрешает запуск: chmod +x run.sh PDaB.x86_64
Unity Editor и Half-Life 2 для запуска этой готовой сборки не требуются.
Нужны Linux x86_64, рабочий графический драйвер и поддержка Vulkan/OpenGL Core.

WASD — движение, мышь — взгляд, Shift — бег, F — фонарик, Esc — пауза.
Фонарик и бег расходуют AUX POWER. Рабочие потолочные лампы защищают от
преследователя; свет фонарика такой защиты не даёт. Найдите выход.
При поимке можно начать заново из меню поражения.
Для проверки: наберите easy во время игры — убрать врага до перезапуска;
наберите tp — переместиться перед выходом, затем пройдите наружу.

Основной режим — полный экран. Интерфейс рассчитан на 1920×1080 и 1920×1200.
При необходимости запустите ./run.sh -screen-width 1920 -screen-height 1200
Для окна: ./run.sh -screen-fullscreen 0 -screen-width 1920 -screen-height 1080

Журнал: ~/.config/unity3d/DefaultCompany/PDaB/Player.log

Учебный неофициальный прототип. В проекте использованы материалы и звуки
Half-Life 2 (Valve); сведения об источниках находятся в исходном проекте,
в Tools/Art/*HalfLife*.json и Tools/Art/StalkerAudioSources.json.
PDaB не является продуктом Valve. Сторонние материалы принадлежат их авторам.
